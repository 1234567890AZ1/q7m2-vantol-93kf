# 生理模块（real-life）· AstrBot 插件

让你的 bot 拥有真人一般的作息和生理状态！目前支持：一日三餐饥饿与讨食、喝水与上厕所暂离、晚间洗澡吹头发、困倦入睡与做梦概率唤醒、28 天生理周期（痛经怕冷与投喂哄人互动），以及日常自主 / 被动听令双模式。

本仓库是 [WhiteBr1ck/aurabot-mod-real-life](https://github.com/WhiteBr1ck/aurabot-mod-real-life) 的 AstrBot 移植版：引擎逻辑保持一致，接入层重写为 AstrBot 插件（`Star`、`filter`、LLM 工具与插件配置页）。

## 安装方式

- **手动安装（推荐）**：把本仓库放进 AstrBot 的 `data/plugins/astrbot_plugin_real_life/`，重启或在 WebUI「插件管理」中重载即可。
- **配置**：在 WebUI「插件管理 → 生理模块 → 配置」中填写 `owner_id`（主人 QQ / 用户 ID），并按需调整作息与周期参数。
- **更新**：`git -C data/plugins/astrbot_plugin_real_life pull` 后在 WebUI 重载插件。

## 核心能力

- **双模式与热聊陪伴优先（daily / passive）**：
  - **日常自主模式（默认）**：没人聊时自己按作息吃一日三餐、去洗手间、洗澡、睡觉；**正在跟主人聊天时一律暂缓**，绝不自作主张消失，急了会在对话里请示主人，经主人同意后才去。
  - **被动听令模式**：全程不擅自进食或切入暂离，一切向主人报告等批准或投喂。
- **一日三餐配额与多聊讨食（diet）**：默认每天固定 **3 顿正餐配额**（早/午/晚，无免费无限零食）。平时不聊天她完全能照顾好自己；跟主人聊得多消耗快时，配额不够垫肚子，就会眼巴巴向主人讨食。
- **三段式听令与极限保底（locks）**：主人下令「不准吃 / 憋着不准去厕所」后会真实上锁，绝不背地偷跑；快满 90 时委屈求饶；仅当熬到 100 极限且主人长时间不在时，才偷喝口水垫一下（`100→80`）或紧急解决，并在下次见到主人时心虚认错。
- **暂离连发 4 条强召回（away）**：上厕所/洗澡/睡觉期间，若主人着急连发达到 **4 条消息**（可在配置修改）或发「快回我/急事」，立即中断暂离秒回，并带上前面未读内容。
- **睡觉与做梦（sleep）**：按时区（默认 `Asia/Shanghai`）计算夜间入睡/起床浮动与午休；推导浅睡、深睡、REM 做梦阶段，睡着时按阶段概率决定能不能被消息吵醒（深睡约 12%，浅睡约 65%，急事加成），醒来带迷糊感并汇总未读消息。
- **月经 / 生理周期（period）**：28±N 天四阶段（经期、卵泡期、排卵期、经前 PMS）。默认**经期前两天反应明显**（小腹坠痛、腰酸怕冷、情绪娇气需要哄/照顾）；经期喂冰奶茶/冰淇淋会触发抽痛加重，喂热红糖姜茶、贴暖宝宝、揉肚子抱抱、吃布洛芬能真实缓解不适并提升亲密与心情。
- **心跳间隔可调**：插件配置支持自定义心跳巡检秒数（默认 `30s`，修改后即时生效，平时零 Token 消耗）。
- **群聊独立开关与隐私保护**：默认关闭群聊（仅私聊生效，群聊不受任何影响）；开启「在群聊中也启用」后，她在群里也会同步表现饥饿、嘴馋、困倦、暂离不插话、睡觉被 `@` 概率吵醒等状态，同时严格隐藏生理期/如厕等私密细节。

## 与 AstrBot 的对接方式

- **上下文注入**：`on_llm_request` 把当前身体与作息体感追加到 system prompt；群聊只注入脱敏后的状态。
- **消息接管**：`event_message_type(ALL)` 在暂离/睡眠时暂存私聊消息并 `stop_event()`，不让消息进入模型。
- **发送防穿帮**：`on_decorating_result` 在暂离/睡梦中拦截该角色的外部消息；斜杠命令回复不受影响。
- **LLM 工具**：`real_life_status`（查状态）、`real_life_interact`（投喂/照顾）、`real_life_routine`（去/禁止/解禁），仅在主人私聊时下发。
- **主动消息**：心跳触发讨食/求哄/归来结算时，通过当前对话模型生成并私聊发送。

## 配置入口与目录位置

- 配置入口：AstrBot WebUI →「插件管理」→「生理模块」→ 配置页
- 插件目录：`data/plugins/astrbot_plugin_real_life/`
- 状态存档：`data/plugin_data/astrbot_plugin_real_life/state.json`（与 AstrBot 数据目录同级）

## 可配置项

所有配置均可在 AstrBot 插件配置页中修改并即时生效：

### 1. 全局与模式防打扰

| 配置项 | 字段名 | 默认值 | 范围 / 可选值 | 说明 |
| --- | --- | --- | --- | --- |
| 启用生理模块 | `enabled` | `true` | `true` / `false` | 模块总开关；暂停后停止后台巡检、提示词注入与消息暂存拦截 |
| 在群聊中也启用 | `groupEnabled` | `false` | `true` / `false` | 默认仅私聊生效；开启后群聊同步拥有饥饿、困倦、暂离不插话、熟睡被 @ 概率吵醒等状态，并严格隐藏生理期/如厕等隐私 |
| 生活自主模式 | `autonomyMode` | `daily` | `daily` / `passive` | `daily`：闲时自理三餐如厕，热聊时暂缓并请示主人；`passive`：全程听令等待主人批准或投喂 |
| 聊天陪伴保护时长 | `chatIdleMinutes` | `15` | `3 ~ 120` 分钟 | 跟主人私聊后的该时长内视为「正在热聊」，期间绝不擅自去上厕所、洗澡、睡觉或自己吃饭 |
| 暂离 / 睡眠强召回条数 | `forceReplyCount` | `4` | `1 ~ 20` 条 | 上厕所、洗澡或睡觉时，主人连发达到该条数（或发「快回我/急事」）立即中断暂离强制秒回 |
| 心跳巡检间隔 | `heartbeatSec` | `30` | `5 ~ 300` 秒 | 后台状态检查与暂离归来结算精度，平时零 Token 消耗，修改即时生效 |
| 作息时区 | `timeZone` | `Asia/Shanghai` | IANA 时区字符串 | 用于计算一日三餐、晚间洗澡、入睡起床与跨天结算的本地时区 |

### 2. 饮食与洗漱暂离

| 配置项 | 字段名 | 默认值 | 范围 / 可选值 | 说明 |
| --- | --- | --- | --- | --- |
| 启用饮食与饥饿系统 | `dietEnabled` | `true` | `true` / `false` | 控制饱食度自然消耗、聊天消耗、三餐自理配额与投喂互动 |
| 早 / 午 / 晚饭点 | `mealTimes` | `08:00, 12:15, 18:30` | 逗号分隔 `HH:MM` | 每日三餐基准时间，每天自动带 `±15` 分钟自然作息浮动 |
| 每日自理正餐配额 | `dailyMealQuota` | `3` | `0 ~ 10` 顿 | 每天最多自己吃几顿正餐；设为 `0` 则不自理正餐，纯靠主人投喂 |
| 每轮私聊消耗饱食度 | `chatHungerCost` | `1.8` | `0 ~ 15` | 每聊一句额外增加的饥饿值（长消息略增），聊得越火热饿得越快 |
| 闲时按配额自理三餐 | `autoMeal` | `true` | `true` / `false` | 关闭后即使处于 `daily` 模式也不会自己吃饭，需主人投喂或批准 |
| 饥饿主动私聊讨食 | `hungerNudge` | `true` | `true` / `false` | 配额耗尽仍挨饿或饿极了时主动私聊主人讨食（每天最多 2 次） |
| 启用上厕所暂离 | `bathroomEnabled` | `true` | `true` / `false` | 饮水进食自然攒尿意；闲时自理、热聊请示，暂离期间自动暂存私聊消息 |
| 启用晚间洗澡 + 吹头发 | `showerEnabled` | `true` | `true` / `false` | 每晚两段式暂离（洗澡约 14 分钟 + 吹头发约 7 分钟），洗完带松弛余韵 |
| 晚间洗澡时间 | `showerAt` | `21:30` | `HH:MM` | 每晚计划洗澡基准时间（每天自动带 `±25` 分钟自然浮动） |

### 3. 睡眠与做梦

| 配置项 | 字段名 | 默认值 | 范围 / 可选值 | 说明 |
| --- | --- | --- | --- | --- |
| 启用睡眠与做梦系统 | `sleepEnabled` | `true` | `true` / `false` | 睡着后按浅睡（65%）、REM 做梦（30%）、深睡（12%）阶段概率决定能否被消息吵醒 |
| 平时入睡时间 | `sleepAt` | `23:30` | `HH:MM` | 夜间入睡基准时间；若到点仍在陪主人热聊，会犯困但绝不擅自断联入睡 |
| 平时起床时间 | `wakeAt` | `07:45` | `HH:MM` | 早晨自然醒基准时间，醒来后自动汇总回复夜间错过的私聊 |
| 允许午后犯困小睡 | `napEnabled` | `true` | `true` / `false` | `13:10 ~ 14:00` 精力偏低且无人聊天时小睡约 35 分钟 |

### 4. 生理周期

| 配置项 | 字段名 | 默认值 | 范围 / 可选值 | 说明 |
| --- | --- | --- | --- | --- |
| 启用 28 天生理周期 | `periodEnabled` | `true` | `true` / `false` | 模拟经期、卵泡期、排卵期、经前 PMS 四阶段，仅对主人私聊展现私密体感 |
| 最近一次经期第 1 天 | `cycleAnchor` | `""`（自动维护） | `YYYY-MM-DD` | 周期锚点日期；留空则使用插件内部存档，切换调试场景时会自动同步 |
| 生理周期天数 | `cycleLength` | `28` | `21 ~ 38` 天 | 完整生理周期的总天数 |
| 每次经期持续天数 | `periodDays` | `5` | `3 ~ 8` 天 | 单次月经持续天数 |
| 经期体感与情绪强度 | `periodSeverity` | `heavy` | `heavy` / `mild` / `intense` | `heavy`：前两天明显坠痛怕冷需哄照顾（推荐）；`mild`：轻微乏力怕凉；`intense`：重度痛经，很依赖止痛药与暖宝宝 |
| 经期难受主动求哄 | `periodNudge` | `true` | `true` / `false` | 经期前两天难受时主动私聊主人求哄照顾（每天最多 1~2 次） |

### 5. 主人身份与主动消息

| 配置项 | 字段名 | 默认值 | 说明 |
| --- | --- | --- | --- |
| 主人 QQ / 用户 ID | `owner_id` | `""` | 识别主人私聊、投放主动消息与启用主人专属工具；留空时回退到 AstrBot 全局 `admins_id` |
| 主人称呼 | `owner_name` | `主人` | 主动消息与提示词中使用的称呼 |
| 主人私聊会话 UMO | `owner_umo` | `""` | 形如 `aiocqhttp:FriendMessage:123456`；一般留空，插件会在主人首次私聊时自动记录 |

## 主人斜杠命令

命令前缀以 AstrBot 配置的唤醒前缀为准（默认 `/`）：

- `/身体`（或 `/身体状态`、`/真人状态`）：查看此刻全景状态
- `/改状态 <键=值 ...>`（或 `/改数值`、`/设状态`）：手动精准改数值，如 `/改状态 饥饿=80 精力=35 膀胱=70 已吃=3 禁食=1 禁厕=1`、`/改状态 解禁=1` 或 `/改状态 不适=自动`
- `/投喂 <食物/饮品> [热|冰|常温] [一小口|半份|一份|管饱]`：例如 `/投喂 红糖姜茶 热 一份`、`/投喂 冰奶茶`
- `/照顾 <方式>`：例如 `/照顾 暖宝宝`、`/照顾 揉肚子`、`/照顾 布洛芬`
- `/身体测试 <场景>`：支持 `经期1`、`经期2`、`经前`、`排卵`、`日常`、`上厕所`、`大号`、`洗澡`、`吹头发`、`深睡`、`浅睡`、`做梦`、`饥饿`、`结算`、`预览`、`重置`
